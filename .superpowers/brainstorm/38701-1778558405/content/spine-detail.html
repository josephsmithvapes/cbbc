01

One CSS rule

The dashed spine is a single repeating-linear-gradient on a position:fixed element — no SVG, no JS, loads before first paint.

02

Section marks

A dot node + 10px tick + label at each section boundary. Each section adds padding-left: 28px on mobile to make room.

03

Mobile-only

Entire spine lives inside @media (max-width: 960px). Zero impact on desktop layout or Lighthouse desktop score.

04

Accessibility

Spine element gets aria-hidden="true". Section labels are decorative and hidden from screen readers — section headings carry the semantic structure.

05

Scope

Spine runs top of page to footer — covers React sections and the static HTML sections (story, merch, capture, invest).
