A

Spine — vertical rule + section callouts

A single dashed gold line runs the full left edge with horizontal tick marks and section labels at each boundary. Clean, technical, minimal. Matches the "spec sheet" quality of the hero.

B

Callouts — per-section annotation overlays

Each section gets its own blueprint callout lines and bracket corners, like the hero SVG's polyline-to-CTA-box pattern. More expressive, more work per section.

C

Thread — scroll-connected nodes

A dashed vertical thread with a dot node at each section, like a timeline or wiring diagram. Structured, guides the eye top to bottom, section numbers as spec references.
