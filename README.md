# Bold Crew Cold Brew

Small-batch cold brew, cold steeped 20 hours, born in Los Angeles.

**[boldcrewcoldbrew.com](https://boldcrewcoldbrew.com)** · **[@BoldCrewColdBrew](https://www.tiktok.com/@boldcrewcoldbrew)**

---

We built BCCB around one idea: full transparency, every batch. Live brew monitoring, real sensor data, and a waitlist that tells you exactly where your order stands. No noise. Just the good stuff.

The site tracks each batch in real time — from grind to steep to ready — with IoT telemetry streamed directly from the brew setup. When a batch completes, the data lives on as a permanent proof record.
